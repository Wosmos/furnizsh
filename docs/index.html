a neon terminal, in one command

One script sets up your whole terminal: the Ghostty Neon theme, a Starship prompt, and faster replacements for the commands you already type. It won't touch the rest of your config.

how it works

Three steps. About five minutes, most of it waiting for downloads.

STEP 01

Clone it

Grab the repo. Nothing is installed yet.

git clone …/afterglow.git
STEP 02

Preview, then run

See every action first with --dry-run, which changes nothing. Then run it for real.

./install.sh --dry-run
STEP 03

Open a new terminal

Then agdoctor confirms every piece works, and chs shows you what you can now do.

renderingno shader

Sharp text, on purpose

A bloom shader and a CRT shader were both tried and dropped. Bloom blurs text by design; the CRT one made scrolling stutter. The look holds up without them.

it won't wreck your setup

Your shell config is load-bearing. An installer that clobbers it costs you an afternoon — so this one is built not to.

preview--dry-run

Read it before you trust it

Prints every action it would take, and changes absolutely nothing. Run this first.

❯./install.sh --dry-run
[dry-run] cp config/ghostty/config ~/.config/…
[dry-run] append source block to ~/.zshrc
nothing was changed
your configappend-only

Your .zshrc survives

The setup lives in its own file. All that's added to your .zshrc is one marked line — your PATH exports, work tooling and aliases are never read or moved.

# your existing config, untouched
# >>> afterglow >>>
source ~/.config/afterglow/afterglow.zsh
# <<< afterglow <<<
backups
[ automatic ]

Everything replaced is kept

Copies of every file it overwrites land in a timestamped folder before anything is written.

rerunning
[ idempotent ]

Safe to run twice

It compares against what's already installed and only changes what actually drifted.

leaving
[ reversible ]

Clean uninstall

./uninstall.sh strips the block and restores your originals — tested to come back byte-for-byte.

consentasks first

Nothing irreversible happens quietly

Changing your login shell, replacing a git pager you already configured, overwriting a profile you wrote by hand — each one stops and asks. Pass --yes only if you want them all approved up front.

Ghostty has no native Windows build — it ships for macOS and Linux only. So on Windows you pick: run everything inside WSL2 and get the setup exactly as described, or install the PowerShell version, which has the same tools and all 24 commands with Windows Terminal and a matching colour scheme. Both routes are written up in full.
